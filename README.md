# Portfolio — GHT Frinel

Portfolio interactif de GHT Frinel, designer numérique basé à Porto-Novo.

## Expérience

- Mini-jeu d’introduction « Connecte les points »
- Navigation multi-page sans rechargement
- Projets éditoriaux et études de cas
- Section services animée au défilement
- Mise en page responsive pour ordinateur et mobile

## Lancer le site

Le projet est statique. Ouvrez `index.html` directement ou servez le dossier avec un serveur HTTP local.

## Technologies

HTML, CSS et JavaScript natifs.
